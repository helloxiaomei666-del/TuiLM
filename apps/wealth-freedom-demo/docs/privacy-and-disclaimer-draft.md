# 隐私政策与免责声明草案

本文档是 MVP 阶段草案，不是正式法律文本。上线前应由专业人士复核。

## 隐私政策草案

### 我们处理哪些数据

当前静态 Demo 仅在用户当前浏览器本地保存以下数据：

- 资产持仓：资产类型、名称、代码、持有数量、成本价、当前价、当前市值、今日盈亏。
- 手动拖累项：类型、标题、每月金额、说明。
- 保障账户：养老金、公积金、补充公积金、企业年金、职业年金的用户手动录入数据。

当前 Demo 不会主动上传数据，不会连接第三方账户，不会要求用户提供交易密码、支付密码或第三方平台登录信息。

### 数据保存位置

当前 Demo 使用浏览器 `localStorage` 保存数据。保存 key 包括：

- `wealth-demo-holdings-v1`
- `wealth-demo-manual-drags-v1`
- `wealth-demo-security-accounts-v1`

用户可以点击页面中的“清除本地数据”删除当前浏览器保存的数据。

### 截图和 OCR

当前 Demo 的截图导入仅用于本地预览和模拟 OCR 回填。真实版本应遵守：

- 用户主动选择截图。
- OCR 识别结果先进入待确认状态。
- 用户可以编辑识别结果。
- 用户确认后才保存。
- 用户未确认的数据不应持久化。

### 数据删除

MVP 必须提供清除入口。后续如果接入账号系统，还应提供：

- 删除当前设备本地数据。
- 删除云端账号数据。
- 注销账号。
- 导出个人数据。

## 免责声明草案

退了吗是个人资产记录和退休进度计算工具。所有计算结果都基于用户自行输入的数据、历史回测数据和简化模型，仅用于个人复盘和参考。

本产品不构成投资建议、理财建议、买卖建议、税务建议、法律建议或任何收益承诺。产品不会推荐具体股票、基金、债券、商品或其他金融产品，也不会提供自动交易能力。

行情数据、OCR 识别结果和模拟计算可能存在延迟、错误或遗漏。用户应自行核对资产数据和识别结果，并对个人财务决策独立负责。

预计退休时间不是承诺结果。实际结果可能受到收入、支出、市场波动、政策变化、家庭责任、健康状况等因素影响。

## 产品表达边界

可以表达：

- 当前资产变化如何影响退休进度。
- 哪些固定支出拖慢退休时间。
- 如果每月多投入一定金额，模型结果如何变化。
- 如果目标拆成阶段，进度如何变化。

禁止表达：

- 买入、卖出、加仓、减仓。
- 抄底、止盈、止损。
- 推荐股票、基金或策略。
- 收益承诺。
- 自动登录或抓取第三方账户。
- 暗示用户必须采取某种金融行为。
