# 测一测你的自由进度

这是一个独立的纯前端 V0.3 微信传播型 H5 自测工具，用来帮助用户基于自己输入的资产、负债、现金流和被动收入，生成一份“自由进度”自我观察报告。

现有《退了吗》 / wealth-freedom-demo 项目未被修改。本项目在独立目录内实现，不复用、不改写、不覆盖既有项目文件。

## 本地打开

可以直接双击或用浏览器打开 `index.html`。所有计算和页面交互都在浏览器本地完成。

推荐用本地静态服务预览：

```bash
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## 测试

运行全部自动化检查：

```bash
node --test tests/*.test.js
```

## V0.2 核心口径

- 现金流退休率是第一核心指标，海报中展示为“自由进度”。
- 目标资产进度只是辅助观察，不能替代现金流覆盖判断。
- 当前净资产 = 总资产 - 总负债。
- 总资产包括现金、基金、股票、黄金、房产估值和其他资产。
- 总负债包括剩余房贷、车贷、消费贷和其他负债。
- 目标退休资产采用目标月生活成本 × 12 × 25 的简化估算。
- 资产模型达标不等于现金流覆盖。
- 现金流覆盖也不代表可以立即辞职，仍需评估稳定性、安全垫、通胀、医疗、家庭责任和极端风险。

## 微信传播型 H5 封装

首页产品名为“测一测你的自由进度”，核心解释是“看看你现在有多少生活成本，已经不用完全靠工资来扛”。入口卖点为“30 秒开始 / 不登录 / 不上传 / 本地生成结果”。

单页应用保留四个逻辑状态：

1. landing：微信传播首页 / 落地页。
2. form：现有五步测算流程。
3. result：突出“我的自由进度”的结果页。
4. poster：自由进度卡预览与保存提示。

用户路径为：点进来 → 开始测一测 → 完成五步测算 → 看到自由进度 → 保存自由进度卡 → 朋友也想测。首页会在存在 LocalStorage 草稿时显示“继续上次测算”；没有草稿时隐藏该入口。

结果页主按钮统一为“保存自由进度卡”，不使用工程化下载文案。海报仍在本机 Canvas 生成；保存时提供“长按图片保存到相册 / 如果无法自动保存，请长按图片保存”的微信内浏览器提示。

## 五步引导式表单

本轮表单从“填写你的退休进度信息”改为“生成你的自由进度报告”。五步标题分别是：

1. 设定你的生活目标
2. 盘点你已经拥有的资产
3. 扣除你仍要偿还的负债
4. 看看你每月能留下多少钱
5. 计算资产每月替你赚多少钱

每一步都包含步骤说明、“这一页会影响什么”提示卡、字段口径解释、实时小结卡和更明确的下一步按钮。桌面端展示完整步骤导航：生活目标、资产、负债、收支、被动收入；移动端保留“第 X / 5 步”和“下一步”提示。

资产页使用“房产估值”，提示用户不要在这里扣除房贷；负债页使用“剩余房贷”。系统统一按“当前净资产 = 总资产 - 总负债”计算，避免用户在资产页先扣除贷款、再在负债页填写房贷导致重复扣减。

实时小结卡改为解释型文案，例如资产小结、净资产小结、每月现金流小结和资产收入小结；金额展示使用整元格式，避免无意义的 `.00` 小数。清空本地数据入口移到表单底部的次级区域，并保留“数据仅保存在当前浏览器，不会上传”的隐私说明。

## 数据与隐私边界

- 项目没有后端、数据库、登录系统或生产网络请求。
- 表单草稿只写入浏览器 LocalStorage，用于本机恢复填写进度。
- 用户数据只保存在当前浏览器，不会上传。
- 页面提供“清空本地数据 / 清空本次数据”控制，会清空本工具保存的本地草稿并重置表单。
- 浏览器隐私模式、存储配额或用户手动清理缓存可能导致草稿无法保存或被清除。

## V0.2 已支持功能

- 微信传播首页、五步表单、结果页和分享海报弹窗。
- 输入当前年龄、目标成本、资产、负债、主动收入、支出、被动收入和半被动收入。
- 引导式五步表单、暖色低饱和视觉、步骤导航、提示卡、解释型实时小结和底部次级清空入口。
- 使用房产估值 + 剩余房贷的口径，避免用户先扣房贷后又重复填写负债。
- 自动换算月度被动收入，生成现金流退休率 / 自由进度、目标资产进度、资产月收入、工资依赖、安全垫月数、保守模型时间和推进器模拟。
- 拆分现金流状态、资产状态和综合判断，避免把资产模型达标误读成现金流已经覆盖生活。
- 基于浏览器 Canvas 生成本地“全民默认版自由进度卡”，并提供文字摘要作为可访问替代内容。
- 表单基础校验、分步错误提示、焦点样式、微信移动端响应式、防横向溢出、iOS 输入字号和减少动态效果适配。

## CTA 与分享边界

- “进入《退了吗》”是后续入口占位，MVP 暂未接入真实地址，也不会跳转到任何外部产品。
- 分享海报只在本机 Canvas 生成；保存图片由浏览器完成，不上传用户数据。
- 没有真实分享链接时，不生成虚假二维码，只保留软 CTA 文案。
- 本工具不推荐任何金融产品，不提供购买、卖出、持有或投保建议。

## 使用声明

测算结果只用于个人财务状态测算和自我观察。结果依赖用户输入和简化假设，不构成投资建议、理财建议、保险建议或退休决策建议；不承诺收益，不预测市场走势。
