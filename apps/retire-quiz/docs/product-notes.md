# 产品说明与合规边界

## 产品定位

“测一测你的自由进度”是一个独立的纯前端微信传播型 H5 自测工具。它把用户输入的资产、负债、现金流、被动收入和半被动收入整理成一组可读指标，帮助用户观察自己离“稳定现金流覆盖目标生活成本”还有多远。

它不是养老金计算器，不接入真实社保、公积金、年金、保险、证券或银行接口，也不验证任何账户权益。

## 微信 H5 封装

本轮封装只处理传播入口、移动端体验和保存海报路径，不重写算法、不修改指标口径、不接入后端。

页面逻辑拆为四个状态：

- landing：微信传播首页，展示“测一测你的自由进度”、核心解释、30 秒开始、不登录、不上传、本地生成结果和合规提示。
- form：沿用现有五步测算流程。
- result：第一屏突出“我的自由进度”和“现在有 XX% 的生活成本，不用完全靠工资来扛”的解释。
- poster：展示自由进度卡预览，并提示用户长按图片保存到相册。

首页“继续上次测算”只在存在本地草稿时显示；返回首页不会清空已经填写的数据。重新测算会清空当前测算并回到表单页。

微信内访问的基础约束是：页面不横向滚动，输入框使用 16px 字号降低 iOS 自动放大概率，按钮保持不小于 44px，海报预览宽度不超过屏幕。

## 指标与公式

## 五步输入体验

输入页的定位不是后台资料录入，而是引导用户生成自己的“自由进度报告”。页面标题统一为“生成你的自由进度报告”，五步流程为：

1. 设定你的生活目标：说明当前年龄、目标生活成本会影响目标退休资产、自由进度解释和保守模型下的目标达成时间。
2. 盘点你已经拥有的资产：说明现金、基金、股票、黄金、房产估值和其他资产会加总为当前总资产。
3. 扣除你仍要偿还的负债：说明剩余房贷、车贷、消费贷和其他负债会从总资产中扣除，得到当前净资产。
4. 看看你每月能留下多少钱：说明月收入、月支出和月可投入金额会影响保守模型下的目标达成时间。
5. 计算资产每月替你赚多少钱：说明稳定被动收入用于计算自由进度，半被动收入只计入资产月收入。

每一步都包含“这一页会影响什么”提示卡、字段口径说明和解释型实时小结。金额展示按整元显示，避免后台式的无意义小数。清空本地数据放在表单底部次级区域，并配套提示“数据仅保存在当前浏览器，不会上传”。

房产字段必须保持为“房产估值”，负债字段必须保持为“剩余房贷”。用户不应在资产页提前扣除房贷；系统统一使用“当前净资产 = 总资产 - 总负债”计算目标资产进度。

### 现金流退休率 / 自由进度

现金流退休率 = 稳定月被动收入 / 目标月生活成本。

稳定月被动收入包括用户填写的股息分红、租金、利息、REITs、已领取养老金、已领取年金、版权收入和其他稳定现金流；不固定收入不计入。海报上用“自由进度”表达这一指标，降低传播理解成本。

### 目标资产进度

目标资产进度 = 当前净资产 / 目标退休资产。

当前净资产 = 总资产 - 总负债。

总资产包括现金、基金、股票、黄金、房产估值和其他资产。

总负债包括剩余房贷、车贷、消费贷和其他负债。

目标退休资产 = 目标月生活成本 × 12 × 25。这里等价于使用 4% 作为简化估算假设，只用于粗略观察，不代表确定收益率、可持续提款率或未来可实现收益。

目标资产进度只是辅助观察。资产模型达标不等于现金流覆盖，真正衡量“不靠工资生活”的核心指标仍然是现金流退休率。

### 资产月收入

资产月收入 = 稳定月被动收入 + 月度半被动收入。

半被动收入仍需要维护、管理或劳动参与，所以只计入资产月收入，不计入现金流退休率。

### 工资依赖

工资依赖 = max(0, 目标月生活成本 - 稳定月被动收入) / 目标月生活成本。

它表示目标生活成本中仍需要工资、主动劳动或其他额外来源承担的比例。

### 安全垫月数

安全垫月数 = 现金 / 当前月生活成本。

安全垫只使用现金，不把基金、股票、黄金、房产估值或其他非现金资产计入应急月数。

### 保守模型时间

保守模型时间使用零收益保守模型，不计算投资回报、资产涨跌、通胀、税费、贷款利率变化或收入增长。

模型先计算剩余目标月成本：

```text
剩余目标月成本 = max(0, 目标月生活成本 - 稳定月被动收入)
```

再计算调整后目标资产：

```text
调整后目标资产 = 剩余目标月成本 × 12 / 0.04
```

再计算：

```text
资产缺口 = 调整后目标资产 - 当前净资产
月可投入金额 = 月工资收入 + 月副业收入 - 月生活支出 - 月固定支出 - 月债务还款
```

若当前净资产已覆盖调整后目标资产，页面表达为“资产模型当前已达标；现金流模型尚未达标”。若月可投入金额小于或等于 0，则不估算具体达成时间。否则显示保守模型估算还需约多少年达到目标资产。

现金流覆盖也不代表可以立即辞职，仍需评估现金流稳定性、安全垫、通胀、医疗、家庭责任和极端风险。

### 推进器

推进器是在基准测算上，分别假设每月稳定被动收入增加 100、500、1000 元，重新计算保守模型时间，并展示相对基准大约可提前多少个月或多少年。

这是数学场景模拟，不是投资建议，也不是推荐用户追求某种收益、产品或资产配置。

## 状态体系

V0.2 拆分三个状态：

- cashFlowStatus：只看现金流退休率。
- assetStatus：只看目标资产进度。
- overallStatus：综合判断，但优先解释现金流是否覆盖。

当现金流退休率低于 100% 时，即使目标资产进度已经达到 100%，也只能说明资产模型达标，不说明稳定现金流已经覆盖生活成本。

## 动态小结与分享卡

分享海报是“全民默认版自由进度卡”，主视觉是自由进度百分比，并包含：

- 目标资产进度。
- 资产月收入。
- 工资依赖。
- 动态阶段标签。
- 动态小结。
- 合规提示。

没有真实分享链接时，不生成虚假二维码，只保留“你也可以测测自己的自由进度”的软 CTA。

## 数据与隐私

数据只保存在当前浏览器。工具不上传用户输入，不接入后端、数据库、登录系统、真实金融账户或外部 API。

如果用户正在使用公共设备，建议测算后点击“清空本地数据”或“清空本次数据”。

## 4% 假设 caveat

4% 只是一个简化估算假设，用来把目标月生活成本换算成粗略资产目标。它不代表确定收益率，不代表未来市场可以实现的收益，不代表安全提款率，也不代表任何投资组合建议。

## 被动、半被动与养老金 caveat

- 稳定被动收入完全依赖用户自行输入，系统不验证真实性、稳定性、税后金额、合同期限或可持续性。
- 半被动收入仍需要维护、管理或劳动参与，所以不计入现金流退休率。
- 养老金、公积金、企业年金、职业年金和商业保险权益不由本工具测算或验证。
- 只有已经领取并由用户填写的养老金或年金，才按所选频率进入当前稳定月被动收入。
- 尚未领取的养老金不计入当前被动收入。
